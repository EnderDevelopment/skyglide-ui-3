# Fly Script UI

This project contains a Roblox script that creates a Fly UI for players. The UI includes a button that allows players to toggle flying mode on and off. The script is designed to be easy to use and integrate into any Roblox game.

## Install

1. Download the `src` folder from the repository.
2. Place the `PlayerGui` folder inside the `StarterGui` service in your Roblox game.

## Use

1. Start the Roblox game.
2. A Fly UI will appear on the player's screen.
3. Click the "Fly" button to toggle flying mode on and off.
